# Claim boundary

SCHRODINGER-001 is a formal root-action/mass handoff only. It is not a claim
that the public repository already contains the full Schrodinger derivation,
the Born rule, a complete quantum theory, a complete electron construction,
or a physical measurement model.

The promoted definitions file contains only the declarations required by this
stage, and only `Schrodinger001RootAction.lean` is promoted in this release.
